## 🔧 Как использовать 3D анимации в компонентах

### Карточки с 3D эффектом
`jsx
<div className="card-3d-hover">
  <!-- Содержимое поворачивается при наведении -->
</div>
`

### Плавающие элементы
`jsx
<div className="float-3d">
  <!-- Плавает в 3D пространстве -->
</div>
`

### Логотипы с вращением
`jsx
<div className="logo-3d">
  <!-- Логотип вращается в 3D при наведении -->
</div>
`

### Кнопки с 3D эффектом
`jsx
<button className="btn-3d-press">
  <!-- Нажимается с 3D эффектом -->
</button>
`

### Свечение в 3D
`jsx
<div className="glow-3d">
  <!-- Пульсирует с 3D масштабированием -->
</div>
`

## 📱 Мобильная оптимизация

### Экраны ≤ 768px (Планшеты, смартфоны горизонтальная):
- Monaco Editor: шрифт 12px, без миникарты
- Панель инструментов внизу редактора
- Увеличенные touch-области (44px+)
- Все 3D анимации ОТКЛЮЧЕНЫ для производительности

### Экраны ≤ 480px (Смартфоны вертикальная):
- Monaco Editor: шрифт 11px, компактная линейка номеров
- LobbyChat: полноэкранное наложение вместо floating panel
- Оптимизированные шрифты и отступы

### Поддержка
- iOS Safari: фиксы для 100vh, предотвращение zoom
- Android Chrome: улучшенная производительность скролла
- Notched devices: safe-area-insets
