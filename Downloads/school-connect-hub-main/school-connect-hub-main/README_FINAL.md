## 📞 Если что-то не работает

### Редактор кода ломается
- Очисти localStorage: F12 → Console → `localStorage.clear()`
- Перезагрузи браузер F5

### Админка не видна
- Проверь что ты админ в profiles (role = 'admin')
- Если нет - выполни UPDATE в SQL Editor
- Очисти localStorage и перезагрузи

### Чат не работает
- Скорее всего, таблица `lobby_messages` не создана
- Выполни SQL_SETUP.sql полностью
