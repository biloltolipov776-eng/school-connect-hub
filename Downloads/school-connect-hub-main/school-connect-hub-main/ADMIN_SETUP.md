# 🔧 ИНСТРУКЦИЯ: Как включить админку

## Статус админки: ❌ Не готова (нужны SQL таблицы)

## Что нужно сделать:

### ШАГ 1: Подготовить SQL (5 минут)
1. Открой Supabase console: https://supabase.com/dashboard
2. Выбери свой проект
3. Слева: SQL Editor → New Query
4. Скопируй ВСЕ содержимое файла SQL_SETUP.sql (выше)
5. Вставь в редактор
6. Нажми ▶️ Run (или Ctrl+Enter)
7. Должно выполниться без ошибок (зелёная галка)

### ШАГ 2: Сделать себя админом
В том же SQL Editor добавь в конец:

\\\sql
UPDATE public.profiles 
SET role = 'admin' 
WHERE email = 'alfacompofficial@gmail.com';
\\\

Нажми Run.

(Если твой email другой - замени на свой)

### ШАГ 3: Перезагрузи браузер
F5 или Cmd+R

### ШАГ 4: Проверь админку
1. На сайте нажми в Header → Админ (должна появиться кнопка)
2. Если не видишь - ещё раз перезагрузи и очисти localStorage:
   - Открой F12 → Console
   - Введи: localStorage.clear()
   - F5

## Что откроется после:

### На странице /admin:
- 📊 **Статистика** - кол-во пользователей, сайтов, онлайн
- 👥 **Список пользователей** - таблица со всеми юзерами
- 🎓 **Лобби** - создание/удаление классов для обучения
- 📝 **Проекты** - просмотр и редактирование кода учеников
- 🔐 **Роли** - система прав (admin, teacher, student)

## Что там можно делать:

✅ **Админ может:**
- Смотреть всех пользователей
- Видеть их проекты (сайты)
- Редактировать код учеников
- Создавать лобби (классы для учеников)
- Менять роли (сделать учителем/убрать права)
- Удалять пользователей

✅ **Учитель может:**
- Создавать свои лобби (классы)
- Добавлять туда учеников
- Видеть их код
- Ставить оценки

✅ **Ученик может:**
- Присоединяться к лобби по коду
- Писать в чат урока
- Видеть свой код в админской консоли

## Структура данных:

### Таблицы:
- \lobby_messages\ - сообщения в чате
- \lobby_participants\ - кто учится на уроке
- \lobby_grades\ - оценки за задания
- \lobbies\ - сами классы/уроки (уже была)

### Функции:
- \is_teacher_or_admin(user_id)\ - проверка прав

### RLS политики:
- Все сообщения видны только участникам урока или админам
- Оценки - только учителям и тому, кому они выставлены
- Участников могут добавлять только учителя

## Если что-то не работает:

❌ \"Админ-панель загрузилась но пустая\"
- Скорее всего, не создались таблицы
- Запусти SQL_SETUP.sql ещё раз

❌ \"Не видно кнопки Админ\"
- Проверь что ты админ: Supabase → profiles → твоя строка → role должен быть 'admin'
- Очисти localStorage (F12 → Console → localStorage.clear())
- Перезагрузи браузер

❌ \"Ошибка при создании лобби\"
- Проверь что таблица \lobbies\ существует (она должна была создаться ранее)
- Если нет - создай вручную (см. выше)

## Примеры использования:

### Как учитель создаёшь урок:
1. Админка → вкладка \"Лобби\"
2. Введи тему: \"Урок 5 - CSS Flexbox\"
3. Выбери язык: \"Web (HTML/CSS/JS)\"
4. Нажми \"Сгенерировать код\"
5. Скопируй код (он появится ниже)
6. Дай этот код ученикам

### Как ученик присоединяется:
1. На сайте ищет поле \"Присоединиться к лобби\"
2. Вводит код учителя
3. Оказывается в классе с чатом и редактором

### Как смотришь код ученика:
1. Админка → вкладка \"Статистика\"
2. В таблице найди ученика
3. Нажми кнопку \"Проект\"
4. Откроется его код (HTML/CSS/JS)
5. Можешь редактировать и сохранять
